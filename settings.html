中转服务 / AI 接口

所有需要调用 AI 的功能（口语 GPT、词库翻译、长难句拆解）都靠这个接口。两种用法：

  • 直连模式（个人推荐）：直接填平台的 API 地址 + 你的 API Key。Key 只保存在你的浏览器本地。
  • 中转模式：用项目里的 relay/ 目录搭建自己的中转服务器，Key 存在服务器，分享网页不会泄露。

💡 常用地址：DeepSeek · Groq · 硅基流动 · AIGC BAR · OpenRouter

☁️ 云端同步

用 6 位登录码同步数据，换设备不丢。
