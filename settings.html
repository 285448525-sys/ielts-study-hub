目标分数

🎤 口语模考

口语模考的「发音分」现在有三种来源，按优先级自动生效：① 配了讯飞发音评测 Key → 每 Part 后做真实朗读检测（最准）；② 没配 Key 但填了下面这项 → 用此固定分兜底；③ 都没配 → DeepSeek 根据转写文字估算发音。下面这项是「可选」的兜底分，不填也能正常模考。

关掉则口语录音只存本地、不调用云端识别（农村网络抖时可关，改用手打/粘贴）。需在 Cloudflare 绑定腾讯云密钥才生效，否则自动降级为手打。

🤖 AI 接口（DeepSeek）

所有 AI 功能（口语对练、词库翻译、长难句拆解、写作批改、错题本讲解）都用 DeepSeek。只需填一个 Key，地址和模型已内置，无需任何其它配置。

获取 Key：platform.deepseek.com（注册送免费额度，国内直连免翻墙）。Key 只存在你的浏览器本地。

🗣 讯飞语音（语音输入 + 发音评测）

讯飞三项密钥现在同时给口语模块提供两样能力：① 更准确的语音转写（IAT）——替代不稳定的浏览器识别，修复"漏词"；② 发音逐词打分（ISE）——跟读参照句做准确度 / 流畅度 / 完整度 + 逐词纠错。两项共用同一套 APPID / APIKey / APISecret。在 讯飞开放平台 建应用获取三项密钥，填一次即用。每日免费 500 次，个人练口语够用。（"测试连接"探活的是发音评测服务，同时也用于语音输入。）

密钥只存在你的浏览器本地；纯前端直连讯飞，无后端。公开部署时密钥会暴露（自用无妨）。

☁️ 云端同步

用手机号绑定云端，多设备数据互通。绑定后默认自动同步，换设备登录同一手机号即可恢复数据。

🌐 常用网址管理

仪表盘「常用网址」模块显示的内容。支持添加、编辑、删除。

🔔 专注提醒

专注（倒计时目标达成或手动结束）时给一点正向反馈。提示音本地合成、无需联网；桌面通知需在浏览器授权。

数据管理

所有数据存在本机浏览器。导出备份后再做危险操作。
