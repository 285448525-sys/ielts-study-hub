账号与会员
免费版和会员差在哪？
学习功能（单词 / 句子 / 口语题库 / 写作 / 回顾）全部免费；差别只在 AI 次数：免费版口语模考每月 1 次、写作批改每月 3 次、其他 AI 每周 5 次；串题素材是会员专属。云同步和导出永久免费。
怎么开通会员？
会员页选档位 → 按说明转账 → 点「我已转账」。当天开通，开通后会员页自动变会员态。
会员到期后数据会丢吗？
不会。学习记录、词库、成绩全部留在你账号里，到期只是 AI 次数回到免费额度。
学习功能
「每日学习上限」是什么？
单词页右上角齿轮里设的那个数。首页的「今天还有 N 个词要过」以它为准，不是全词库到期量。设 0 = 不限。
错词本在哪？
单词页右上角。答错过的词按错误次数分档，重练不占今日配额。
计时是自动开的吗？
是。在单词页答题、模考做题、口语练习都会自动开始计时，不用手动开。
数据与同步
换设备数据还在吗？
在。登录同一个账号，学习记录自动同步。也可以随时在设置里导出 JSON 备份。
遇到问题怎么反馈？
设置页「写反馈」或本页底部的「写反馈」。带截图更容易定位。
